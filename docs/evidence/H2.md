# H2 Evidence — Real Paper Broker (Event-Sourced)

Branch: `codex/harness-m3c-security` (H0 `bd5c3b0` → H1/M3c `b305106`).
Date: 2026-11-02. Offline, deterministic, no keys, no network.

## What replaced what

The CLI paper mode previously ran `CountingHook` (intent counting,
`Lamports::ZERO` spends). It now runs the event-sourced `PaperBroker`
(`crates/sniper-runtime/src/broker.rs`) through `PaperBrokerHook`; observe
and replay modes keep `CountingHook` unchanged. A reported paper buy MUST
now leave a non-zero position when fill criteria pass (asserted by CLI
tests), per the mission contract.

## Design

- **Event-sourced**: every mutation appends a command to a JSONL ledger
  (`place`/`settle`/`observe`/`migrate`). `PaperBroker::replay_ledger`
  re-executes the identical deterministic commands, so crash recovery
  rebuilds cash, positions, realized P&L, drawdown, and closed trades
  bit-identically (test: `crash_recovery_rebuilds_from_ledger_and_continues`).
- **Fills** price with the existing M3 math (`paper_buy`/`paper_sell`):
  fee-in on entry, fee-out on exit, plus adverse slippage (bps from
  config), priority network fee + tip per fill, one-time Token-2022 ATA
  rent per mint (values match the fork-observed costs: 5,000 fee /
  1,513,920 rent — M3c evidence).
- **No-lookahead**: an order carries its decision-time snapshot; `settle`
  prices ONLY against it. A newer, better observation arriving before
  settlement cannot improve the fill
  (`settle_uses_decision_snapshot_not_newer_observation`). Stale
  snapshots (age > `max_snapshot_age_slots`) never fill.
- **No-fill taxonomy**: `StaleSnapshot`, `MinOutUnmet` (insufficient
  exit liquidity / min-out guard), `InsufficientCash`,
  `InsufficientPosition`, `UnknownOrder` — all typed, tested, counted.
- **Migration**: `apply_migration` switches the position's venue and the
  marking/pricing source; quantity and cost basis survive
  (`migration_mid_position_switches_venue_and_pricing`).
- **Marking**: `equity_mark_to_exit` = cash + every open position priced
  at its EXECUTABLE exit (whole-position sell into the latest observed
  state, net of exit fees/slippage/network). Peak-to-trough drawdown
  tracked on every mutation.
- **Deterministic timestamps**: slots drive ms (slot×400; fills land at
  decision+70ms) so `features_observed ≤ decided ≤ entry ≤ exit` always
  holds — enforced independently by the evaluator.
