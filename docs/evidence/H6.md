## H6-2 — Bounded read-only creation-cohort collector (Python)

Files: `harness/launch_cohort_capture.py`, `harness/tests/test_launch_cohort_capture.py`.

- Explicit bounded slot window (hard cap 10,000 slots) or race-free tip-relative `--recent-slots N`.
- Mainnet genesis (`5eykt4UsFv8P8NJdTREpY1vzqKqZKvdpKuc147dw2N9d`) verified BEFORE any market read; wrong cluster refuses with zero market calls (tested).
- Completeness derives ONLY from `getBlock` evidence over every slot plus signature/block reconciliation. `getSignaturesForAddress` is candidate discovery, never a completeness proof — enforced and documented.
- Decodes versioned `CreateEvent` (create / create_v2 instruction variants), prefix-tolerant 19-field layout mirroring the Rust decoder; failed transactions yield no creates; duplicates deduplicated by (signature, ordinal).
- Gaps are explicit kinds (`RateLimited`, `ProviderUnavailable`, `MissingMetadata:<sig>`, `NoBlockEvidence:<sig>`); transactions recovered without block evidence yield creates flagged `block_evidence=false`, `transaction_index=null` — never fabricated; window past tip is right-CENSORED; no evidence is UNKNOWN.
- Outputs write-once (exclusive create, fsync, chmod 0444): raw_creates JSONL + content-addressed manifest (dataset sha256 in filename and body). Permanently `nonpromotable: true`.
