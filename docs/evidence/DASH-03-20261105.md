## 2. Reproduction (exact commands + results)

### 2.1 What was built

**Server-side mode isolation (the operator's mandatory architecture):**
- `TradeMode` enum in `sniper-observability::queries` — `REAL_MONEY` iff sealed `proof_state == "LIVE_CONFIRMED"`, else `PAPER`. Classification copies the sealed label; it never rewrites evidence (T-MODE3).
- `list_runs_in(mode)` filters at the query layer; `ensure_run_mode()` refuses any run of the other scope — wired into EVERY run-scoped endpoint via `resolve_run_id(db, run, mode)`; `/runs?mode=`, `/strategies?mode=`; invalid `mode` values are 400 (never silently ignored).
- Tests T-MODE1..4 in `crates/sniper-dashboard-api/tests/api.rs` (incl. a hand-sealed `LIVE_CONFIRMED` fixture): paper-only-in-paper, live-only-in-real-money, direct-API bypass refused (404 `mode isolation refused this run` on all six endpoints), no cross-mode strategy aggregation.

**Frontend (`apps/dashboard`):** React 18 + TypeScript + Vite 5 + Tailwind 3.4 (DESIGN.md tokens as CSS vars, dark default + light), Radix deps pinned, TanStack Query/Table, Recharts (fees bar + table fallback), Lucide icons, `@fontsource` Fira Sans/Code bundled locally (zero external network calls — enforced by an e2e route guard that throws on any non-loopback request). Five pages: Command Center, PnL Analytics, PnL Calendar, Portfolio, Execution — all wired to `/api/v1/*` through a same-origin Vite proxy; every request carries the active mode so the API boundary enforces isolation. Mode selector in the header is a **read-only view switch**: switching clears the entire query cache, resets the run selection, persists `?mode=&run=` in the URL (deep-linkable; nav links carry params), shows PAPER banner (`PAPER / SIMULATED · NOT REAL MONEY`) or Real-Money banner (`LIVE TRADING DISABLED / NO VERIFIED REAL TRADES` — the honest default today).

**Launcher:** `scripts/dashboard-dev.sh` — builds the API, starts it at `http://127.0.0.1:7433` with a fresh `--rebuild`, waits for health, starts the frontend at `http://127.0.0.1:5173`.
