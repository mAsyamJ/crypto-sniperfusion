## E. Budget-stop summary regression — found in production, fixed, regression-tested (VERIFIED_CODE)

**Defect:** the first live budget-stop ever exercised crashed `main()` with `KeyError: 'blocks_fetched'` — `_budget_stop_report` built a minimal report missing the summary keys `main()` unconditionally indexes (`blocks_fetched`, `pages_fetched`, `raw_path`, `manifest_path`, `creates`, `gaps`). Prior sessions never ran a budget-stop through the summary path; the existing test asserted only `status`/`coverage_state`.

**Fix:** `_budget_stop_report(from_slot, to_slot, out_dir, reason, checkpoint=None)` now carries the same summary keys as a completed run, populated from the checkpoint saved after the last completed unit of work (raise happens post-`save()`; verified at `harness/launch_cohort_capture.py` save-sites): `blocks_fetched`, `pages_fetched`, `creates`, `gaps`, `raw_path`/`manifest_path` (`None` — no manifest is written on a stop), `requests_used`, `collected_to_slot`, `checkpoint` path. Both raise-sites (`capture`, `capture_recent_slots`) pass the checkpoint. Progress numbers are "so far", never a completeness claim; `coverage_state` stays `INCOMPLETE`.

**Regression test:** `test_budget_stop_report_carries_summary_keys_regression` exercises the exact `main()` extraction contract on a budget-stopped capture and asserts checkpoint-derived progress ≥ actual work done.
